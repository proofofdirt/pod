## Objective

Build an open-source ML model that scores **cattle, sheep, and goat body condition** from geotagged field photographs taken by Turmi field agents. The model is used to monitor livestock health in oracle-tracked animal husbandry cycles — confirming animals are gaining weight on schedule before each fattening tranche disbursement is approved.

---

## Why This Is Needed

Live animal and Halal carcass meat exports to MENA are a primary MVP commodity. Investors financing animal fattening cycles need periodic verification that animals are developing correctly — not just alive, but progressing on the expected weight gain curve.

Manual veterinary visits are expensive and logistically difficult at scale across the Omo Valley. Satellite cannot monitor individual animals. Agent-captured photos with ML-driven BCS scoring is the practical verification solution that makes livestock vaults trustworthy.

**Disbursement gate:** An oracle-gated tranche for a livestock vendor is not approved unless the Oracle confirms a BCS score ≥ 2.5 (and improvement trajectory from the prior check) with confidence ≥ 0.80.

> **Architectural constraint (V1):** Ethiopian law prohibits stablecoin/cryptocurrency transactions. The Oracle does **not** move money. A confirmed BCS milestone emits a tranche approval event; PODRWA SPV (KSA) executes the disbursement as a **fiat bank wire** to Turmi (or another Ethiopian operator). Fully on-chain settlement is a V2 goal, contingent on Ethiopian regulation.

## Technical Requirements

### Input
- Single geotagged JPEG or PNG photograph of an individual animal
- Lateral (side-on) view preferred; model should handle partial frontal/rear views
- Photo metadata: GPS coordinates, timestamp, agent ID

### Output
```json
{
  "species": "cattle",
  "bcs_score": 3.1,
  "confidence": 0.87,
  "flag": false,
  "flag_reason": null,
  "inference_time_ms": 340
}
```

### BCS Scale (Standard 1–5)
| Score | Condition | Meaning |
|---|---|---|
| 1.0 | Emaciated | Animal welfare concern — flag immediately |
| 2.0 | Thin | Below acceptable fattening floor — flag |
| 2.5 – 3.5 | Moderate to good | Target range for active fattening |
| 4.0 | Fat | Monitor for over-conditioning |
| 4.5 – 5.0 | Obese | Over-conditioning — flag for veterinary review |

**Flag triggers:**
- BCS < 2.0 — animal welfare concern → flag + block tranche approval + request veterinary escalation
- BCS > 4.5 — over-conditioning → flag + notify vault manager

### Technical Constraints
- **Min. confidence:** ≥ 0.80 before on-chain Oracle PDA write
- **Inference speed:** Must run in ≤ 2 seconds on a mid-range Android device (e.g., Samsung Galaxy A-series) for real-time field use
- **Robustness:** Handle variable field photo quality, natural lighting conditions, partial animal occlusion, background clutter
- **Species scope:** Cattle, sheep, goats (three separate scoring heads or multi-task model)

## Target Breeds

Model must be calibrated to Ethiopian livestock breeds common in the Omo Valley and SNNP Region:

- **Cattle:** Borana (large frame, hump-back Zebu) and Arsi (smaller, highland-adapted)
- **Sheep:** Blackhead Ogaden (primary MENA export breed — fat-tailed, black head)
- **Goats:** Local mixed varieties (contact [email protected] for specifics)

Transfer learning from general animal detection or livestock models is strongly encouraged — do not attempt to train from scratch.

## Technical Approach

The model should:
1. Detect the animal in the frame (object detection or segmentation head)
2. Extract body key points or region features (topline, hip bones, rib visibility, tail head)
3. Regress a BCS score from 1.0–5.0 in 0.5-point increments
4. Output a calibrated confidence score (not raw softmax — use temperature scaling or Platt scaling)

**Recommended architectures:**
- EfficientNet-B3 or MobileNetV3 backbone (for mobile inference speed)
- Keypoint-based approach using animal pose estimation as an intermediate step
- Multi-task head: species classification + BCS regression

**Evaluation metric:** Mean Absolute Error (MAE) vs. ground truth veterinary BCS score. Target MAE < 0.5 BCS points on the validation set.
