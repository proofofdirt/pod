# BOUNTY SOC-001 — Discord Community Bot

**Reward:** USDC or SOL, paid by direct transfer from the DAO treasury multisig (grant/donation-funded; amount published on the bounty issue)  
**Status:** Open  
**Repo:** pod-social

## What to Build
A Discord bot for the POD community server implementing the commands in `discord/config.md`.

## Requirements
- `/bounty list` — fetch open bounties from GitHub API
- `/plot status [plot_id]` — query Oracle API for plot verification status
- `/tranche status [plot_id]` — query oracle PDA for tranche verification history
- Offline-safe: graceful degradation if Oracle API is unreachable
- Written in TypeScript (discord.js v14)

## Acceptance Criteria
- All commands working on the POD Discord test server
- Test coverage > 70%
- Deployed to a VPS or Railway with uptime monitoring
