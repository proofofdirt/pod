# Financier Dashboard (buyers, DFIs, Ethiopian FI partners)

- Public (logged-in): unfunded farms + estimated financing requirement, ROI (insurance-inclusive),
  buyer discount terms, producer credit score band
- Private (financing party only, post-funding): SAR plowing, NDVI/yield, RFID animal records,
  BCS scoring, tranche history, export + settlement status, repayment
- SPV/FI ops queue: tranche approval events -> fiat wire execution -> disbursement hash recorded
