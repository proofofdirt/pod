# Workflow: New Corridor Proposal → Activation

## Trigger
Community member submits corridor proposal via GitHub Discussions (corridor-proposal template).

## Step-by-step

1. **Engagement Agent** acknowledges submission, assigns proposal ID (CORR-XXX)
2. **Capital Structuring Agent** runs financial feasibility model (volume, FX, costs)
3. **Legal Agent** reviews investment law for both countries
4. **Compliance Agent** checks AML/KYC and regulatory requirements
5. **Orchestrator** compiles feasibility report, posts to GitHub Discussion
6. Community discussion period: 7 days minimum
7. **DAO vote:** 7-day window, simple majority, 10% quorum
8. If APPROVED: **Corridor Agent** activates ops parameters · **Capital Structuring Agent** builds financial model
9. If REJECTED: documented rationale posted · resubmission allowed after 90 days
