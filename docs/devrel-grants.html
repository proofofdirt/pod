Application Workflow

1
Identify — Weekly scan

Every Monday: ask Claude to search for new open grant calls matching Proof of Dirt (prompt below). Score relevance 1–3. Add any 2–3 rated opportunities to tracker. Set reminder for deadline –4 weeks.

2
Brief — 1-page fit summary

For each opportunity you decide to pursue: write a 1-page brief covering fit, required effort, estimated timeline, and any eligibility questions. Share with Supervisor A for go/no-go decision before spending time drafting.

3
Draft — Claude-assisted

Use the Claude drafting prompt below. Claude writes the technical sections (oracle architecture, satellite pipeline, Solana program design). You write the narrative (why Ethiopia, team story, impact model). Never submit a draft without supervisor review.

4
Review & Budget

Supervisor A reviews technical accuracy. Add a budget table: personnel (intern hours), infrastructure (GEE, RPC nodes, server), travel (if applicable), overhead. Budget must be realistic — do not inflate.

5
Submit & Log

Submit through funder portal. Record submission date, confirmation number, and expected response timeline in tracker. Set calendar reminder for follow-up at 4 weeks if no response.

6
Report (for active grants)

Most grants require progress reports at 3, 6, and 12 months. Link deliverables to GitHub milestones and releases. Use the reporting template below.

Technical Section Prompt

## Claude prompt for grant technical sections

You are writing the technical section of a grant application for Proof of Dirt.

PROJECT SUMMARY:
Proof of Dirt (Proof of Dirt) is a decentralized agricultural finance protocol on
Solana that enables Ethiopian smallholder livestock farmers to access structured
export finance via blockchain-backed vaults. The pilot corridor is West Ethiopia
(UKE Welega, Horo Guduru Welega Zone) → MENA markets (KSA, UAE, Kuwait, Qatar,
Oman, Bahrain, Egypt, Jordan).

TECHNICAL COMPONENTS:
1. Vault Program (Anchor/Rust on Solana): records fiat (SAR/USD)
   financing positions arranged via the SPV, maintains plain on-chain records,
   and approves tranches when oracle conditions are met. No funds are held or
   moved on-chain in V1 — Ethiopia prohibits stablecoins/crypto, so the SPV wires
   fiat to the Ethiopian operator (Turmi) on each on-chain tranche approval.
   Fully on-chain settlement is planned for V2, when Ethiopian regulation allows.
2. Oracle feeds (Switchboard v2): monthly MENA livestock prices (10 feeds across
   8 markets), SAR plowing proof, NDVI crop health score, yield prediction.
3. Satellite pipeline (Google Earth Engine Phase 1): Sentinel-1 SAR plowing
   detection, Sentinel-2 NDVI time series for UKE Welega AOI.
4. Bounty system (Anchor program): on-chain task marketplace for field agents
   (GPS+photo evidence) and developers (GitHub PRs).
5. Agent app (React Native, offline-first): critical for field use in low-connectivity Ethiopia.
6. Web interfaces: financier dashboard (Next.js, public unfunded-farm view + private funded view) and
   agent dashboard (wallet-required).

GRANT FUNDER: [insert funder name and program]
SECTION TO WRITE: [e.g. "Technical Approach — 500 words"]
FOCUS: [e.g. "emphasize the open oracle data and satellite verification"]
