DAO Governance & Funding — No Token

Core policy: the project does not mint or issue a token. A token added complexity without adding trust. The DAO operates on grants and donations, pays contributors directly, and keeps all financing verification on-chain as plain records. The name "$DIRT" is retired except as a possible future label for a non-transferable on-chain recordkeeping instrument for fiat transactions — to be introduced only if recordkeeping genuinely requires it, by governance vote.

2. DAO Structure

  • Treasury multisig: 3-of-5 (Squads). Signers represent the full chain — developers (a supervisor/builder seat), producers/field operations (Gutu, Ground Truth Leader), buyers (an offtake-partner representative), plus Bekam and one external advisor. Proof of Dirt is a community-owned, builder-managed DAO: every key decision (treasury disbursements, bounty payouts, oracle parameter changes, financing rules) requires multisig approval — no single party controls the treasury or the rules.
  • Decisions: routine disbursements 3/5; payment-policy changes, new signers, and any future recordkeeping-instrument proposal require 3/5 plus 7-day community notice.
  • Signer elections — 12-month terms: every multisig seat is elected. Each year, every seat goes to a community vote to keep or replace the signer; candidates must be active contributors in the seat's constituency (developers, producers/field ops, buyers, coordinator, advisor). The election result is executed on-chain as a Squads member-change proposal (configure member-management at multisig setup), so both the vote outcome and the key rotation are permanent public records. A signer who resigns or goes inactive mid-term is replaced by interim 3/5 vote, with the seat confirmed at the next election.
  • Oracle integrity rule: oracle feeds are the sole reference for tranche verification. No manual override by any team member or signer.

4. Transparency & Reporting

  • Monthly treasury snapshot (crypto wallet balance + Ethiopian account balance) in #treasury-log.
  • Quarterly grant/donation report to the community; annual public report.
  • Grant applications and award letters archived in docs/financiers/.

5. Future On-Chain Recordkeeping (conditional)

If fiat transaction recordkeeping ever requires an on-chain instrument beyond plain records and events, the DAO may introduce a non-transferable receipt record (working name $DIRT) by governance vote. It would carry no monetary value, no transferability, and no fundraising function — bookkeeping only. Until that vote happens, it does not exist.
