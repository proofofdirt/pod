# Trade Restriction Alert Sources

Subscribe to these to receive proactive notifications. Do not rely on manual checks alone.

---

## Set Up Now (email subscriptions -- free)

| Source | What you get | Subscribe |
|---|---|---|
| **OIE/WOAH Disease Events** | Email alert when Ethiopia reports disease event | woah.int/en/disease-events -- click "Subscribe to alerts" |
| **USDA APHIS Animal Disease Status** | Weekly summary of global animal disease status | aphis.usda.gov/aphis/ourfocus/animalhealth -- sign up for updates |
| **FAO GIEWS Country Brief: Ethiopia** | Monthly food security + livestock update | fao.org/giews -- subscribe to Ethiopia country brief |
| **FAO GIEWS Country Brief: Saudi Arabia** | Monthly import/demand update | fao.org/giews -- subscribe to Saudi Arabia country brief |

## Forwarding Rule

Set up email rule: any OIE/USDA APHIS alert mentioning Ethiopia + [RVF / FMD / PPR / LSD] →
forward immediately to ops+analytics@proofofdirt.com and ops@proofofdirt.com.

Subject line template for manual alerts:
[RESTRICTION WATCH] [Disease/Event] detected in Ethiopia -- [date] -- monitor for ban
[RESTRICTION ALERT] [Market] bans Ethiopian [commodity] -- [date] -- capital exposure review needed
